# Security Policy

## Supported Versions

The `master` branch is the only actively maintained version. Security fixes are applied there and released as new tags.

## Reporting a Vulnerability

If you discover a security vulnerability in FamilyTree, please report it privately rather than opening a public issue.

- Open a [GitHub Security Advisory](https://github.com/piyushparkash/FamilyTree/security/advisories/new) for this repository, or
- Contact the maintainer via the profile linked at [github.com/piyushparkash](https://github.com/piyushparkash).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (PoC if possible)
- Affected version/commit

You can expect an initial response within a few days. Confirmed vulnerabilities will be patched and disclosed via a GitHub Security Advisory once a fix is available.

Please do not disclose the issue publicly until a fix has been released.
