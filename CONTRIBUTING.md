# Contributing to FamilyTree

Thanks for considering a contribution.

## Getting started

1. Fork the repo and clone your fork.
2. Follow the [Installation](README.md#installation) steps in the README to get a local environment running.
3. Create a branch off `master` for your change: `git checkout -b fix/short-description`.

## Making changes

- Keep changes focused — one fix/feature per PR.
- Match existing code style in the file you're editing.
- Test your change locally before opening a PR (there's no CI test suite yet, so manual verification matters).

## Submitting a PR

1. Push your branch and open a pull request against `master`.
2. Describe what changed and why, and link any related issue.
3. Be responsive to review feedback.

## Reporting bugs / requesting features

Open an [issue](https://github.com/piyushparkash/FamilyTree/issues) with steps to reproduce (for bugs) or a clear description of the use case (for features).

## Security issues

Do not open a public issue for security vulnerabilities — see [SECURITY.md](SECURITY.md).
